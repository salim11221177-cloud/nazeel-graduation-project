# حالات استخدام النظام

## المستخدم

- إنشاء حساب جديد.
- تسجيل الدخول.
- البحث عن الفنادق.
- مشاهدة تفاصيل الفندق.
- مشاهدة الغرف والأسعار.
- اختيار تاريخ الحجز.
- تنفيذ الحجز.
- مشاهدة الحجوزات.
- إلغاء الحجز.

## الفندق

- تسجيل الفندق في النظام.
- إضافة بيانات الفندق.
- إضافة الغرف والأسعار.
- تحديث بيانات الغرف والخدمات.
- متابعة الحجوزات.
- قبول أو إدارة الحجوزات.
- تحديث حالة الغرف.

## مدير النظام

- إدارة المستخدمين.
- إدارة الفنادق.
- إدارة الحجوزات.
- إدارة الخدمات السياحية.
- متابعة النظام.
- إدارة الصلاحيات.
- مراجعة التقارير.

## الهدف

توضح حالات الاستخدام الوظائف الرئيسية التي يمكن لكل مستخدم تنفيذها داخل النظام.
