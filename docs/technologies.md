# التقنيات المستخدمة

## واجهة المستخدم

- HTML
- CSS
- JavaScript

## البرمجة

- JavaScript
- إمكانية استخدام إطار عمل حديث مستقبلًا حسب متطلبات المشروع.

## قاعدة البيانات

- MySQL أو PostgreSQL

## إدارة المشروع

- GitHub
- Git
- GitHub Actions

## التصميم

- تصميم متجاوب يعمل على الهاتف والكمبيوتر وال tablet.

## الأمان

- حماية حسابات المستخدمين.
- تشفير كلمات المرور.
- التحقق من صلاحيات المستخدمين.
- حماية بيانات الحجوزات والمدفوعات.

## قابلية التطوير

تم تصميم المشروع بحيث يمكن إضافة تطبيق للهواتف، ونظام دفع إلكتروني، والإشعارات، والتقييمات والعروض السياحية مستقبلًا.
