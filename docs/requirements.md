# متطلبات النظام

## المتطلبات الوظيفية

1. تسجيل المستخدم وإنشاء حساب.
2. تسجيل الدخول والخروج.
3. البحث عن الفنادق والخدمات السياحية.
4. عرض بيانات الفنادق والخدمات والأسعار.
5. عرض صور ومعلومات الفندق.
6. اختيار تاريخ الوصول والمغادرة.
7. تنفيذ الحجز الإلكتروني.
8. عرض الحجوزات السابقة والحالية.
9. إلغاء الحجز وفق شروط النظام.
10. إدارة بيانات الفنادق والغرف والخدمات.
11. إدارة المستخدمين والحجوزات.
12. توفير لوحة تحكم للإدارة.

## المتطلبات غير الوظيفية

- سهولة استخدام النظام.
- سرعة الاستجابة.
- حماية بيانات المستخدمين.
- توافق النظام مع الهواتف وأجهزة الحاسوب.
- إمكانية تطوير النظام مستقبلًا.
- توفر النظام بشكل مستمر.
